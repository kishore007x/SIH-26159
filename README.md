# SecureMailScope

**AI-assisted cryptographic security posture assessment for email communications.**
SecureMailScope passively analyses PCAP/PCAPNG captures containing SMTP, IMAP and POP3 traffic, reconstructs
the email and TLS sessions, evaluates their cryptography and turns raw packets into prioritised,
evidence-linked findings — entirely inside the browser (no capture data ever leaves the analyst's machine).

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production bundle in dist/
```

Click **Analyze live demo capture** on the landing page, or drop your own `.pcap` / `.pcapng`.

## What is real (not mocked)

| Layer | Implementation |
|---|---|
| Capture decoding | `src/engine/capture.ts` — libpcap (µs/ns, both endians) + PCAPNG (SHB/IDB/EPB/SPB); Ethernet, VLAN, Linux SLL/SLL2, loopback, raw IP; IPv4/IPv6 → TCP |
| TCP reassembly | `src/engine/streams.ts` — per-direction sequence ordering, retransmission trimming, byte→frame mapping for evidence |
| Email sessions | `src/engine/email.ts` — SMTP/IMAP/POP3 state machines, STARTTLS/STLS detection, capability parsing, AUTH LOGIN/PLAIN, USER/PASS, mail-transaction extraction |
| TLS | `src/engine/tls.ts` — record + handshake parsing: ClientHello (versions, suites, SNI, groups, key shares, FALLBACK_SCSV), ServerHello (incl. TLS 1.3 supported_versions), Certificate, ServerKeyExchange, alerts |
| X.509 | `src/engine/x509.ts` — DER/ASN.1 decoder: subject, issuer, validity, key algorithm/size/curve, signature algorithm, SAN, basicConstraints, SHA-256 fingerprint |
| Rules | `src/engine/rules.ts` — 18 checks (STARTTLS stripping, plaintext credentials, refused STARTTLS fallback, command injection, deprecated TLS, weak/NULL/EXPORT ciphers, no PFS, weak DH, expired / weak-key / SHA-1 / self-signed / mismatched certificates …) |
| Intelligence | `src/engine/intel.ts` — per-service cryptographic baselines & drift, TLS fallback-dance correlation, certificate-lineage tracking, Isolation Forest anomaly detection, explainable ordinal risk model, multidimensional posture scoring |

## Demo captures

`public/samples/` contains two captures generated by `scripts/gen-pcap.mjs` with real X.509 certificates from
`scripts/gen-certs.sh` (OpenSSL). They are valid captures — open them in Wireshark to cross-check every frame number
the dashboard cites.

* **acme-mail-incident.pcap** — 17 sessions: STARTTLS stripping (`250-XXXXXXXA`), cleartext AUTH LOGIN and POP3 USER/PASS,
  454 STARTTLS refusal with plaintext fallback, CVE-2011-0411-style command injection, TLS 1.3 → TLS 1.0/RC4 fallback dance,
  interception certificate (same CN, foreign CA), expired RSA-1024/SHA-1 self-signed POP3S cert, static-RSA 3DES/CBC suites.
* **acme-mail-hardened.pcapng** — the same infrastructure after remediation (scores A).

Regenerate with `npm run gen:certs && npm run gen:pcap`. `node scripts/smoke.ts` runs the engine headless.
